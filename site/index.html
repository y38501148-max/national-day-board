SCORING RULES

挑战如何变成分数

注册题 A 不计分。其余题目达到 60% 后，全部参与计算。

  1. 难度带来更多贡献h(r) = 800 × (r / 800)3/2

    1600 题的基础贡献约为 800 题的 2.83 倍。

  2. 完成度奖励
    完成度60%70%80%90%95%100%
    系数 g(s)0.600.750.901.001.051.10

    节点之间线性插值；60% 以下贡献为 0。

  3. 每题保留历史最佳贡献c = max [h(r) × g(s) × max(0.96ⁿ, 0.80)]

    n 为该次提交之前低于 60% 的失败次数。CE、待评测和系统错误不计罚。后续失败不会降低已保留的贡献。

  4. 全题排序并衰减w(k) = 0.60 + 0.40 × 0.90k−1

    按题目 rating 从高到低排序，同 rating 按贡献、题目 ID 排序。第 1 题权重为 1，后续趋近于 0.60，没有题数截断。

  5. 非线性显示 RatingS = Σ w(k)c(k)
    Rating = ⌊15000 × ln(1 + S / 10000)⌋

    没有硬上限。同整数 Rating 并列排名。正常新增提交的得分不下降；重判或规则纠正后会重新计算。
JOIN THE BOARD

在 A 题注册你的公开 ID

使用自己的 OJ 账号提交 A 题，首次 AC 程序的标准输出就是你的公开榜单 ID。下面是一个 C 示例。

#include <stdio.h>
int main() {
    puts("国庆小猫");
    return 0;
}

将 国庆小猫 改为自己的匿名 ID，例如 摸鱼选手_7。允许 1–20 个字符，可用中文汉字、英文字母、数字、下划线和连字符，且至少包含一个汉字、字母或数字；不允许空格、控制字符或 emoji。允许不同选手使用相同 ID，请避免使用真实姓名或学号。

提交前请检查

每个真实学号以本场 A 题的第一次 AC 注册。允许重名；CE、WA 或未完成评测不占用注册机会，可修改后重提。注册成功后再次提交不会自动改名。

注册成功后，系统会补计该账号在比赛有效时间内的已有成绩。SPJ 只检查输出格式，无需联网。第一次 AC 后等待后台校验身份并完成绑定；同名选手各自保留成绩和排名。
